# behavioral-intervention-inference-audit

This folder contains the prompt to generate the intervention audit tool discussed in:

Reiff, J. S., and Bogard, J. E. (2026). “Behavioral Intervention Construal: A Framework for Understanding Inferences from Behavioral Interventions.” Organization Science, Articles in Advance. https://doi.org/10.1287/orsc.2025.21412.

The paper described this tool as available in ChatGPT. The "Custom GPT" function that was used to create the original tool will be retired on December 11, 2026. This prompt serves as a replacement. It serves as a general prompt that can be used with any model.

In ChatGPT, anyone can recreate the tool by:

Openning the Plugins directory and installing Plugin Creator.

Start a new chat, select @plugin-creator, and attach the Markdown file.

Send this message: "Create a private ChatGPT plugin named Behavioral Intervention Inference Audit. Use the attached Markdown file as the instructions for a reusable skill."

In Claude, anyone can recreate the tool by:

Starting a new chat and attaching the Markdown file. 

Sending this message: "/skill-creator can you turn this into a skill?" 

Claude will create named behavioral-intervention-audit, and Claude will validate it and send back a .skill file. 

Click Save skill on the file card to install it.

Once saved, describe or attach an intervention and ask how people might interpret it. The skill or plugin should trigger automatically; you don't need to attach the Markdown file again.

Note that these models are frequently changing. The software-specific instructions above may become obsolete. In this case, we suggest providing this readme file to your AI and asking it for updated instructions on how to create the respective skill.
